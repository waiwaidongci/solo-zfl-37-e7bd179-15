# 墨锭试磨室 · 标签与库位盘点台

墨锭建档/试磨之外，新增**标签发放**、**带容量上限的库位**和**库位盘点台**。

运行：

```bash
npm start          # http://localhost:3037
npm run verify     # 端到端自动验证（换签/错位/离线/并发/回滚/重启）
```

数据保存在 `data/ink-stick-testing.json`（可用 `DB_PATH` 覆盖）。
首次启动会把旧版数据（墨锭的 `storage` 文本）自动迁移为库位，并为每枚旧墨锭补一枚活跃标签。

## 角色

页面右上角可切换：

- **管理员**：维护库位（名称、容量上限、删除）、分批发标签、换签、移库、批量打印。
- **盘点人**：按库位开始盘点、扫码、查看分类与进度、结束并得到冻结的差异清单。

管理员接口要求请求头 `X-Role: admin`。

## 业务规则

- **库位容量**：发签/移库不得超过容量上限；容量不能下调到低于在用标签数；非空或有进行中盘点的库位不能删除。
- **标签短码唯一**：自动码（`MQ`+流水）或管理员指定码，在**全部历史（含作废）**范围内不得重复；一批发放要么整体成功，要么整体失败。
- **换签 / 移库**：旧码立即置为作废并记录新码；扫旧码返回 409 `void_code_rejected`，指出墨锭当前所在库位与有效码，拒绝入账。
- **盘点扫码分类**：在位 `match`、重复 `duplicate`、未知 `unknown`、错位 `misplaced`（标签属于其他库位，提示应在位置）。
- **同库位并发盘点**：一个库位同时只允许一个进行中盘点；同 `clientKey` 的断网重试幂等复用，其他人并发开始返回 409。
- **每条扫码带 `eventKey`**：断网本地排队，恢复后逐条重放，服务端按 `eventKey` 去重，**一条扫码只入账一次**（不会误算成重复）。
- **结束盘点**：`idemKey` 幂等，并发/重复结束只成功一次；结束时生成差异清单（漏扫、错位、未知、重复）**深快照冻结**，之后换签、移库、新盘点都不会改变它；结束后扫码返回 409。
- **离线**：盘点人断网时扫码进入浏览器本地队列（`localStorage`），恢复后自动提交；结束请求离线时也排队，恢复后只生效一次。
- **原子写盘**：所有写操作经互斥锁串行，写入走「临时文件 + fsync + rename」。写盘失败时整笔事务丢弃，标签、库位、扫描事件、差异记录都不会留下半条数据；磁盘上原有文件保持完整。

## 页面

- 墨锭（原有建档/试磨/评分）
- 库位（容量进度条、调容、删除）
- 标签（分批发放、换签/移库、按库位与状态筛选、Code39 条码批量打印）
- 盘点台（扫码枪/键盘输入，支持 `BarcodeDetector` 摄像头；实时四分类与进度；冻结差异清单；历史盘点）
- 手机视口可用，批量打印走浏览器打印（标签纸两列布局）。

## 主要接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST | `/api/locations` `/api/admin/locations` | 库位列表 / 建库位（管理员） |
| PATCH/DELETE | `/api/admin/locations/:id` | 改容量、删除（管理员） |
| POST | `/api/admin/labels/issue` | 分批发标签 `{locationId, entries:[{itemCode, code?}]}` |
| POST | `/api/admin/labels/:code/replace` | 换签 `{newCode}` |
| POST | `/api/admin/labels/:code/move` | 移库换签 `{locationId, newCode}` |
| GET | `/api/labels` `/api/lookup?code=` | 标签列表 / 查码（含作废码当前库位） |
| POST | `/api/sessions` | 开始/恢复盘点 `{locationId, counter, clientKey}` |
| POST | `/api/sessions/:id/scans` | 扫码 `{code, eventKey}` |
| POST | `/api/sessions/:id/finish` | 结束 `{idemKey}`，返回冻结差异清单 |

写接口可带 `Idem-Key` 头做通用 HTTP 幂等。

## 验证

`npm run verify` 会用临时数据文件启动服务并自动覆盖：

角色鉴权、容量上限、短码唯一（含作废码不可复用）、整批失败、
换签旧码拒绝并指出当前库位、错位识别、离线 `eventKey` 重放只入账一次、
同库位并发开始互斥、并发/重复结束只成功一次、差异冻结后换签移库不变、
写盘注入故障时四类记录整笔回滚、重启后数据与冻结差异保留、页面资源可访问。
